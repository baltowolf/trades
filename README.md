# MOEX Stock Tracker v5 — sell-only

Трекер только для продаж. На входе — [`portfolio.json`](portfolio.json:1) с тикером,
количеством, средней ценой покупки и необязательной прогнозной ценой.
На выходе — Telegram-уведомления, когда формулы говорят продавать.

Никаких `fundamentals.json`, `ideas.json`, P/E, P/B и скринеров заполнять не нужно.

## Вход

```json
{
  "SBER": {
    "count": 14,
    "buy_price": 285.99,
    "target": 380.0
  },
  "LKOH": {
    "count": 1,
    "buy_price": 6065.5
  },
  "CASH": 10448
}
```

- `count` — количество акций.
- `buy_price` — средняя цена покупки (для P&L, налога и безубытка).
- `target` — необязательная прогнозная цена. Можно не указывать.
- `stop` — необязательный ручной стоп. Если нет, стоп строится по ATR.
- `CASH` — свободные деньги, только для дашборда.

Если `target` ниже текущей цены, скрипт сразу пришлёт сигнал «ЦЕЛЬ» — прогноз уже достигнут.
Если `target` нет, цели строятся по ATR.

## Что приходит в Telegram

- **СТОП** — цена упала до стопа или ниже; продать всю позицию.
- **TP1 / TP2 / ЦЕЛЬ** — частичная фиксация или полное закрытие.
- **ГОРИЗОНТ** — прошло 120 дней с начала плана; продать всю позицию.

В каждом сообщении: цена, средняя покупка, P&L, точное количество акций и лотов,
чистый результат после комиссии и НДФЛ, остаток и новый стоп.

## Формулы

### Старт плана

```text
plan_anchor = текущая цена на момент первого запуска/сброса плана
initial_stop = plan_anchor - min(3 * ATR, 18% * plan_anchor)
R = plan_anchor - initial_stop
```

Если в `portfolio.json` указан `stop`, он используется вместо ATR-стопа.

### Без target — ATR-ладдер

| Ступень | Уровень | Доля исходной позиции |
|---|---|---|
| TP1 | `plan_anchor + 2 ATR` | 40% |
| TP2 | `plan_anchor + 4 ATR` | 30% |
| TP3 | `plan_anchor + 6 ATR` | весь остаток |

### С target

```text
target_r = (target - plan_anchor) / R
```

- `target_r >= 3`: TP1 = 1R (40%), TP2 = 2R (30%), финал = target (остаток).
- `1 <= target_r < 3`: TP1 = 1R (50%), финал = target (остаток).
- `target_r < 1`: продать всё по target.
- `target <= plan_anchor`: продать всё сразу, цель уже достигнута.

Последняя ступень всегда продаёт весь остаток.

### Стопы

- Chandelier: `peak - 3 ATR`.
- После TP1: стоп в безубыток с учётом комиссии и НДФЛ, плюс `plan_anchor + 0.25R`.
- После TP2: `plan_anchor + 1R`.
- До TP1: если цена дошла до `plan_anchor + 0.75R`, стоп поднимается до `plan_anchor + 0.25R`.
- `stop_current` только повышается, никогда не понижается.
- Стоп-триггер считается по `min(last, bid)` — по цене, по которой реально можно продать.

### Горизонт

Через 120 дней с начала плана — продать всю позицию. Это защита от «зависших» позиций.

## Команды

| Команда | Назначение |
|---|---|
| `python moex_tracker.py` | основной цикл |
| `python moex_tracker.py --once` | одна диагностическая итерация |
| `python moex_tracker.py --show` | последние уведомления |
| `python moex_tracker.py --send-pending` | дослать неотправленное в Telegram |
| `python moex_tracker.py --stats` | статистика закрытых сделок |
| `python moex_tracker.py --migrate` | backup и сброс state |
| `python moex_tracker.py --reset-plan TICKER` | пересчитать план от текущей цены |
| `python test_fixes.py` | самотесты |

## Запуск

```bash
pip install requests
cp .env.example .env
# заполните TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID

python test_fixes.py
python moex_tracker.py --once
python moex_tracker.py
```

`--once` полезен для первой проверки: он покажет дашборд и все текущие планы.
Если Telegram не настроен, сообщения печатаются в консоль.

## После продажи

Скрипт не выставляет заявки. После исполнения обновите [`portfolio.json`](portfolio.json:1):

- частичная продажа — уменьшите `count`;
- полная продажа — удалите тикер или поставьте `count: 0`.

Если этого не сделать, скрипт считает, что рекомендация ещё не исполнена, и не будет
спамить повторными сообщениями по той же ступени. Для ручного пересчёта используйте
`--reset-plan TICKER`.

## Что удалено

- Обязательные `fundamentals.json` и `ideas.json` — больше не читаются.
- Скринер, входной движок, Kelly, корреляционные кластеры и прочая сложность.
- Ядро и спутник — все акции продаются по общим правилам.

## Ограничения

- Скрипт не выставляет заявки и не гарантирует прибыль.
- Цели по ATR — технические, а не фундаментальные.
- Дивиденды и налоговый вычет по убыткам не моделируются.
- Проскальзывание не учитывается в отчётном P&L (только комиссия и НДФЛ).
- `target` — это ваша прогнозная цена; скрипт не проверяет её обоснованность.

## Дисклеймер

Это инструмент расчёта и уведомлений, а не инвестиционная рекомендация.
Решение об исполнении принимает владелец капитала.
