# MOEX Stock Tracker

Профессиональный трекер и риск-менеджер для среднесрочного инвестирования в акции Московской Биржи (MOEX TQBR) и физическое золото (БПИФ GOLD) с уведомлениями в Telegram.

## Архитектура и принципы стратегии

1. **Модель «Ядро / Спутник» (Core / Satellite)**:
   - **Ядро (`core_count`)**: неприкосновенная стратегическая долгосрочная часть позиции. Робот никогда не продает акции ядра по сигналам тейк-профитов или стоп-лоссов.
   - **Спутник**: спекулятивная/активная часть позиции, торгуемая по волатильности (ATR). Строгое выравнивание по биржевым лотам.
2. **Математическое ожидание и фиксация прибыли**:
   - TP1 (2.5 ATR, фиксация 25% спутника) — строго соблюдает Risk/Reward $\ge$ 1.0 относительно начального риска (2.5 ATR).
   - TP2 (4.0 ATR, фиксация 30% спутника).
   - TP3 (6.0 ATR, фиксация 35% спутника).
   - Защита pre-TP1: при достижении `buy + 2.0 ATR` стоп переносится в безубыток `buy + 0.5 ATR`.
   - Chandelier Exit: трейлинг-стоп на расстоянии 3.0 ATR от исторического максимума позиции (`highest_high`).
3. **Фундаментальный контроль Баффета**:
   - Фильтрация компаний с устойчивым экономическим рвом (Moat), положительным свободным денежным потоком (FCF), `Net Debt / EBITDA < 3.0x` и `ROE >= 10%`.
   - Регулярный аудит портфеля по базе `fundamentals.json` с предупреждениями об ухудшении бизнеса.
4. **Финансовая надежность и безопасность**:
   - Нулевая зависимость от тяжелых библиотек: чистый Python 3.14 + `requests`.
   - Атомарная запись состояния (`write-to-tmp` + `os.fsync()` + `os.replace()`) исключает повреждение файлов при сбое питания.
   - Секретные ключи хранятся исключительно в `.env` и никогда не попадают в систему контроля версий.

## Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/baltowolf/trades.git
   cd trades
   ```

2. Установите зависимость:
   ```bash
   pip install requests
   ```

3. Настройте конфигурацию в `.env`:
   ```bash
   cp .env.example .env
   # Заполните TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
   ```

4. Запустите тесты и проверку целостности:
   ```bash
   python test_fixes.py
   ```

5. Запуск трекера:
   ```bash
   python moex_tracker.py
   ```

## Команды

- `python moex_tracker.py` — основной торговый цикл (опрос MOEX ISS каждые 600 с в торговые часы)
- `python moex_tracker.py --show` — просмотр истории последних уведомлений
- `python moex_tracker.py --send-pending` — повторная отправка неотправленных сообщений Telegram
- `python moex_tracker.py --audit-buffett` — ручной запуск фундаментального аудита портфеля
- `python test_fixes.py` — запуск набора регрессионных тестов и самопроверок
